# KCENGMap

ZWCAD / AutoCAD 배경지도 플러그인 — **배포용 저장소**입니다.

이 저장소에는 **설치 파일(Setup.exe)만** 올라갑니다. 소스 코드는 사내 저장소에서 관리합니다.

## 다운로드

최신 설치 파일은 [Releases](../../releases/latest) 에서 받으세요.

## 버전 표기

`KCENGMap.yymm.aa.bb`

| 자리 | 의미 |
|---|---|
| `yymm` | 빌드 년월 (예: `2607` = 2026년 7월) |
| `aa` | 그 달에 **기능이 추가**될 때 증가 |
| `bb` | 기능은 그대로, **개선·버그 수정** 시 증가 |

월이 바뀌면 `aa`/`bb`는 0으로 초기화됩니다. `yymm`이 맨 앞이라 버전 순서는 항상 증가합니다.

각 릴리스 노트에는 빌드에 사용된 커밋 해시가 함께 기록됩니다.

## 설치

내려받은 `KCENGMap.<버전>.exe` 를 실행하면 됩니다.
관리자 권한은 필요하지 않습니다 (사용자 폴더에 설치됩니다).

설치 후에는 ZWCAD / AutoCAD 를 **완전히 종료했다가 다시 시작**해야 새 버전이 적용됩니다.
